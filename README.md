This is a short analysis and modeling project done using NBA team, location, individual game, and various other data to assess the effects of scheduling and travel distance on game results and overall team performances.
Within these results, numerous questions are answered through EDA and regression modelling to find out NBA trends by team, by season, and game-to-game.

Analyzed multi-season NBA scheduling trends using game timing, location, team performance, opponent win %, and travel
metrics across 5+ seasons and 6,000+ games

-Quantified team-level 4-in-6 stretch frequency; applied statistical tests to flag schedule outliers (NumPy, SciPy)

-Measured field goal % impact when facing opponents on back-to-back games

-Modeled league-wide trends in back-to-backs and travel miles per game by season, identifying a downward trend in B2Bs
and increased travel efficiency (NumPy, Matplotlib)

-Built random forest regression model to estimate schedule-driven win differentials, explaining ~15–25% of win variance
with travel and rest as top features (scikit-learn)


You'll find results and answers in the .html or .pdf files that include "Project_Results."
